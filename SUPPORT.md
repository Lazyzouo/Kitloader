# Support / 支持

## Before opening an issue / 提交 Issue 前

1. Confirm Paper/Folia 1.21.11 and Java 21.
2. Confirm the JAR came from [official Releases](https://github.com/Lazyzouo/Kitloader/releases): `Kitloader-en.us.jar` or `Kitloader-zh.cn.jar`.
3. Test with the latest matching language package and attach the startup version banner.
4. Redact player UUIDs, IP addresses, authentication data, and private configuration values.

1. 确认使用 Paper/Folia 1.21.11 与 Java 21。
2. 确认 JAR 来自[官方 Releases](https://github.com/Lazyzouo/Kitloader/releases)：`Kitloader-en.us.jar` 或 `Kitloader-zh.cn.jar`。
3. 使用最新对应语言包测试，并附上启动版本横幅。
4. 删除玩家 UUID、IP、鉴权信息和私密配置参数。

Use the appropriate GitHub issue template for bugs and feature requests. Configuration questions should include only the relevant redacted section and expected behavior.

请使用对应的 GitHub Issue 模板提交错误或功能请求。配置问题只应包含已脱敏的相关配置段与预期行为。
